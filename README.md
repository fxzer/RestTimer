## 它能解决什么问题？

- **一忙起来就忘了时间**：用温和、有节奏的提醒，帮你定时离开屏幕，缓解眼干、颈椎酸痛与久坐疲劳。
- **提醒总是来得不是时候**：正在高速打字、开语音会议或全屏演示时，自动避让顺延，不会突然弹屏打断关键时刻。
- **休息时不知道做什么**：直接为你安排好科学的工位拉伸动作与轻盈名言，让短短 2 分钟真正放松身心。
- **担心音乐或视频被打断**：休息开始自动暂停播放，戴着耳机时休息结束还会自动为你续播。

## 适合哪些人使用？

- **长期面对电脑的职场人**：程序员、设计师、产品经理、文案编辑、科研与金融从业者。
- **多屏办公用户**：外接大屏也能同步遮罩与提示，不会出现“一块屏休息、另一块屏继续工作”的尴尬。
- **频繁开会与演示的团队成员**：在线会议、语音沟通、全屏播放视频或演示 PPT 时自动免打扰。
- **想养成规律作息习惯的人**：通过每日与每周节律统计，直观看到自己的专注与休息习惯变化。

## 核心功能

### 1. 科学的专注与防久坐节奏
- **开箱即用的预设**：默认「30 分钟专注 + 2 分钟休息 + 提前 2 分钟提醒」，内置「20 分护眼」「30 分标准」「45 分深度」三档快捷模式，单次专注上限 60 分钟，防止过度透支。
- **直观的拨盘与菜单栏**：提供可拖拽调节的 60 分钟圆盘表盘；菜单栏以实时圆环展示倒计时，点击即可随时休息、暂停或重置。

### 2. 懂分寸的智能防打断
- **操作中自动顺延**：检测到你正专注敲键盘或操作鼠标时，会自动推迟休息（可自定义顺延触发时间与最长顺延上限）。
- **短暂离开不误清零**：短时间起身倒水、看手机或锁屏回来，不会轻易重置当前专注进度；长时间离开后回归则自动重新开始计时。
- **会议与全屏自动避让**：语音/视频会议、全屏观影或演示期间自动推迟休息，结束后无缝恢复。
- **媒体联动与耳机续播**：进入休息时自动暂停音乐或视频；若佩戴耳机，休息结束自动恢复播放。

### 3. 赏心悦目的全屏护眼与拉伸引导
- **多屏实时同步**：覆盖所有已连接显示器，外接显示器插拔也能即时适配，主题与拉伸进度多屏同步。
- **12 款护眼主题**：涵盖冷调静音、柔和护眼与深色极光三大风格，支持自动轮换，并可在设置中随时无损预览。
- **20 招办公拉伸库**：覆盖**颈部、肩背、手腕、腰脊、臀腿**五大部位，按休息时长自动编排不重复；支持「单张大图」与「三张并排」切换，搭配 60 条精选短句放松心情。
- **轻盈的悬浮提示**：提前提醒、顺延与休息结束时，以柔和的毛玻璃悬浮胶囊轻声告知，不抢焦点。

### 4. 看得见的身体节律统计
- **今日与本周双视角**：清晰记录休息次数、累计休息时长、最长连坐时长与完成率。
- **一目了然的可视化图表**：包含每日 `08:00–23:00` 呼吸节律时间轴、近 7 天柱状图与近 16 周健康热力图，帮你持续保持好节奏。

## 休息页常用快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `←` / `→` / `Space` | 切换上一个 / 下一个拉伸动作 |
| `Tab` | 切换下一个身体部位（颈部 → 肩背 → 手腕 → 腰脊 → 臀腿） |
| `V` | 切换「单张大图 / 多张并排」视图 |
| `M` | 切换「静谧呼吸模式」（隐藏或显示拉伸卡片） |
| `⌘⇧Esc` 或连按 3 次 `Esc` | 紧急退出全屏休息（预览模式下按一次 `Esc` 即可退出） |
